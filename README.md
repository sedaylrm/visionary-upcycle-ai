
# Visionary Upcycle AI
Eski kıyafetleri yapay zeka ile analiz edip farklı moda akımlarına göre yeniden tasarlayan çevre dostu web uygulaması.

**Nasıl Çalıştırılır?**
1. Gerekli kütüphaneleri yükleyin: `pip install -r requirements.txt`
2. Proje klasöründe bir `.env` dosyası oluşturup kendi API anahtarınızı ekleyin: `GEMINI_API_KEY=sifreniz`
3. Uygulamayı başlatın: `python -m streamlit run app.py`
